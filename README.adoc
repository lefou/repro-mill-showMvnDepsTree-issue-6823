# Reproduce Mill issue https://github.com/com-lihaoyi/mill/issues/6823
:toc:
:tocplacement: preamble

## Reproduction

Run `showMvnDepsTree` and notice, it never returns.

```console
> MILL_VERSION=1.1.8 mill -i cloud.vaadin.showMvnDepsTree
...
```

Instead, we would expect to see a tree of all transitive dependencies as output.

## Debugging

When started as shown above, you can attach to the JVM running class `mill.daemon.MillNoDaemonMain` with the Debugger or Profiler of your choice.

## Workaround (to see the desired tree)

First some preparation to install thirdparty libs and the project itself into the local ivy repository.

```console
> MILL_VERSION=1.1.8 mill __:ProvisionModule.publishLocalCached
...

> mill cloud.vaadin.publishLocal --transitive true
...
3033] Publishing de.acme:de.acme.cmfs.cloud.vaadin:0.0.0.0002 to ivy repo /home/lefou/.ivy2/local
```


Now run coursier `cs` tool to show the dependency tree

